# v0.4 visual planting planner

The Plan tab now displays a per-bed 50 cm cell grid for a selected date. Occupied cells display abbreviated crop names, and a date control changes the visible occupancy. Tapping a cell populates the starting coordinate in the existing planting form. Existing space-time validation remains authoritative; planting area is entered as width/depth in cells. A bed occupancy percentage is displayed. Tests cover date-dependent occupancy, overlapping allocations, succession and bed boundaries.

Limitations: this is a tap-to-position planner, not drag-to-paint or touch resize. Crops are not yet visualised on the overall garden canvas. Date windows are manually selected and recommendations/task scheduling remain future milestones.
